# 🔥 BlazeWave Example Demos

This directory contains hands-on demos to showcase BlazeWave’s real-time WebSocket capabilities. Each example is self-contained and demonstrates a practical use case for event-driven, real-time applications.

---

## Available Demos

- **Shared Mascot Demo**: A collaborative demo where users can move the Golang mascot and see all online users and usernames in real time.  
  See full details and usage: [shared-mascot/README.md](./shared-mascot/README.md)

- **Chat Demo**: A real-time group chat where users can join, pick a username, and exchange messages instantly.  
  See full details and usage: [chat/README.md](./chat/README.md)

---

For setup, features, and advanced usage, please refer to each demo’s README above.

Experience how BlazeWave makes real-time collaboration and chat simple and robust!
